# Scan Barcode Online Gratis - ScanBarcode Pro

**Alat pemindai barcode & QR code online gratis terbaik di Indonesia.**  
Scan langsung dari kamera HP atau upload gambar. Tanpa aplikasi, 100% privat, super cepat.

🔗 **Live Demo**: [https://scanbarcode-pro.vercel.app](https://scanbarcode-pro.vercel.app)

---

## Fitur Utama

- Live Camera Scanner (real-time)
- Upload gambar barcode / QR
- Support 50+ format: EAN-13, EAN-8, UPC-A, Code 128, Code 39, QR Code, Data Matrix, PDF417, Aztec, dll.
- QR Code Generator (dengan logo & custom warna)
- 100% Client-side (data tidak pernah dikirim ke server)
- Fully Bahasa Indonesia
- Tanpa iklan mengganggu
- Mobile-friendly & cepat

---

## Cara Menggunakan

1. Buka [https://scanbarcode-pro.vercel.app](https://scanbarcode-pro.vercel.app)
2. Klik **Mulai Kamera**
3. Izinkan akses kamera
4. Arahkan ke barcode / QR Code
5. Hasil langsung muncul otomatis

Atau gunakan fitur **Upload Gambar** jika kamera bermasalah.

---

## Teknologi

- WebAssembly + ZXing
- HTML5 Camera API
- Pure Client-side processing
- Responsive Design

✅ Format Barcode yang Didukung Free Online Barcode Scanner

ScanBarcode Pro free online barcode scanner mendukung lebih dari 50 format barcode yang berbeda. Ini menjadikannya salah satu scanner online paling lengkap yang tersedia di Indonesia.

Barcode 1D (Linear)

  • EAN-13: Standar barcode 13 digit untuk produk retail global, paling umum di Indonesia
  • EAN-8: Versi pendek EAN untuk produk kecil seperti permen dan rokok
  • UPC-A: Standar 12 digit untuk produk impor dari Amerika Serikat
  • UPC-E: Versi kompak UPC untuk kemasan kecil
  • Code 128: Format serbaguna untuk logistik, pengiriman, dan inventori
  • Code 39: Format alfanumerik untuk industri otomotif dan militer
  • Code 93: Versi lebih padat dari Code 39 dengan keamanan lebih baik
  • ITF-14: Untuk karton dan kemasan besar di gudang
  • Codabar: Untuk perpustakaan, bank darah, dan kurir
  • MSI Plessey: Untuk retail dan manajemen gudang

Barcode 2D (Matrix)

  • QR Code: Format paling populer untuk berbagai keperluan digital
  • DataMatrix: Untuk industri elektronik dan komponen kecil
  • PDF417: Untuk dokumen, KTP, SIM, dan identifikasi
  • Aztec Code: Untuk tiket transportasi dan boarding pass
  • MaxiCode: Untuk pengiriman UPS dan logistik internasional
